# Snèh AI

> Snèh AI (Sneh AI) is a private, web-connected AI assistant developed by DBC Technologies (DBC Technologies Narwana) in collaboration with VIDHI Projects Chandigarh.

## Overview & Architecture
- **Inference Infrastructure**: Built using high-speed model routing (including Sneh llm 3.3 and Sneh Enigma llm architectures) via optimized inference hardware.
- **Privacy Architecture**: Designed with privacy-first data routing where user conversations are not stored persistently or used to train public language models.
- **Web Grounding**: Includes integrated search tools for real-time web verification and source retrieval.
- **Platform Availability**: Accessible via web browser and installable as a Progressive Web Application (PWA) across mobile and desktop devices.
