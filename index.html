Sneh AI — Private AI Assistant

Sneh AI is a high-speed, web-grounded AI companion developed by DBC (DBC Technologies Narwana) in partnership with VIDHI Projects Chandigarh.

Technical Features & Proof Points

  • Sneh-V3® LPU™ Hardware Acceleration: Ultra-low latency response streaming using dedicated Language Processing Unit infrastructure.
  • Zero-Retention Message Privacy: Messages are held in RAM during generation and never stored or used to train public LLMs.
  • Live Web Grounding: Real-time internet search capability for up-to-date factual queries and citation generation.
  • PWA & Offline Installation: Installable on Android, iOS, Windows, and macOS as an offline-capable Progressive Web Application.
